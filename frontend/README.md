# IntegraX Frontend (Next.js 16)

This directory contains the user interface and document audit interface for **IntegraX**, built with Next.js 16 (App Router), TypeScript, and Tailwind CSS.

## 🚀 Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```

3. Open **[http://localhost:3000](http://localhost:3000)** in your browser.

## 📦 Features
- **Contract Risk Analysis Dashboard:** Upload PDFs and view instant categorized findings (Risks, Deadlines, Obligations, Key Clauses).
- **Verbatim Quote Verification:** Deterministic matching against original document text.
- **Export PDF Report:** Generate client-ready audit reports directly from the browser.
- **Verified Advocate Directory:** Search Bar Council advocates with one-click direct email, phone call, and consultation booking.
